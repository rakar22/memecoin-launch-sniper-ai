# memecoin-launch-sniper-ai

Solana memecoin **intelligence + paper execution** desk.

It does **not** promise profit. It detects launches, scores security / sellability / distribution, and only then simulates an entry. LIVE is locked.

## Quick start

```bash
cp .env.example .env
npm install
npm run typecheck
npm test
npm run benchmark
npm run dev
```

Dashboard: http://localhost:8787/dashboard
